Getting Started

ReBrowse Pro uses the Gemini AI to power its intelligent features. To get started, you'll need to add your own Gemini API key.

  1. Click the ReBrowse Pro icon in your browser toolbar to open the popup.
  2. In the "API Configuration" section, paste your Gemini API key. You can get one for free from Google AI Studio.
  3. Click the "Save" button. The extension will automatically test the connection.

Once your key is saved, you can start using all the AI-powered features!

Key Features

  • 🎨 Theme Presets: Instantly change the look of any website with themes like Focus, Hacker, or Dark Mode.
  • 🧠 AI Auto-Detect: Let the AI choose the best theme for the page you're on.
  • 📝 Summarize & Key Points: Get a quick summary or the main highlights of any article.
  • 🌐 Translate: Translate web content into dozens of languages.
  • ♿ A11y Check: Get quick, actionable tips to improve a site's accessibility.
  • ⚙️ Font Control: Easily adjust the font size for perfect readability.

You're all set! Open the extension on any webpage to begin.
